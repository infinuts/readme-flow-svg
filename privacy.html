Privacy policy

Last updated: October 15, 2026

This policy covers the readme-flow-svg editor, SVG API, and MCP tools maintained by infinuts on GitHub. Copies hosted by other people may handle data differently. The project has no accounts, advertising, or analytics, and does not sell your data.

Editing in your browser

The editor renders previews and downloads SVGs in your browser. It saves your latest workflow settings, including labels, in local storage under readme-flow-config. Your page appearance preference is saved under readme-flow-appearance. These values stay on your device until you replace them or clear the site's browser data. The app does not use tracking cookies.

The hosted editor's stylesheet loads interface fonts from Google Fonts, so your browser makes requests to Google even if you use a built-in font for your workflow. Those requests include ordinary connection information, such as your IP address and browser headers. Workflow labels are not added to these font requests by the app.

Hosted images, shared links, and API requests

Hosted image URLs and editor links contain your workflow settings in their query parameters, including labels, titles, and connections. Anyone with a link can read those settings. Opening a hosted link sends its URL to the host. Embedding an image in a README also lets the image host or an image proxy fetch and cache it. Keep private information and secrets out of shared workflows. Downloaded SVGs contain their labels too.

The /generate API and generate_workflow MCP tool receive the workflow settings you submit and return an SVG and links. The list_options tool returns supported settings without needing workflow content. The server does not save workflows to a database or publish files to your repository. A client such as ChatGPT handles the tool arguments and results under its own privacy policy; this service receives the tool request, not your full conversation.

Optional Google Fonts for workflows

When you choose a Google Font for a workflow, the editor requests its family and weight from our /font endpoint. The server fetches the font from fonts.googleapis.com and fonts.gstatic.com. It sends the family and weight to Google, without workflow text. API and MCP generation make the same font requests when a Google Font is selected. Font files are cached in memory and used to turn text into paths in the SVG.

Hosting, logs, and retention

Vercel hosts the public editor and API. The static editor is also available through GitHub Pages. Hosting providers process connection data such as IP addresses, request times, URLs, and browser headers to deliver and protect their services. Request URLs can include workflow settings. Hosting logs and cached responses may outlast a request; the project does not promise a fixed deletion period for records held by these providers. The SVG API allows public caching, so clearing your browser data does not remove copies cached elsewhere.

See the privacy policies for Vercel, GitHub, Google, and, if you use the ChatGPT integration, OpenAI.

Your choices and contacting us

Clear this site's browser data to remove saved settings. For workflows you want to keep off the image service, use built-in workflow fonts and download the SVG for your repository. You can open the editor locally; without a network connection, the interface uses fallback fonts. Your MCP client may keep its own tool history, which you manage through that client's settings.

For privacy questions or requests about data the project controls, contact the maintainer through GitHub's private reporting form. A GitHub account is required. Please do not put private workflow links or personal data in public issues. We will review what we can access or remove; copies held by other services need to be handled with those services.

Changes to this policy will appear on this page with an updated date.
