First comment:

I made readme-flow-svg to explain a project's path from input to output without
recording a video or using a drawing app.

The editor is vanilla JavaScript and CSS. It exports a self-contained SVG with
CSS animation, icons, and reduced-motion support. It also works by opening the
HTML file directly. You can arrange 3–12 steps, add branches or loops, and choose
an SVG palette independently of the page's light/dark appearance.

Editing and SVG downloads happen in the browser. Hosted image links use a
stateless service and include the workflow settings in their public URL. Optional
Google Fonts loading sends only the family and weight; built-in fonts and a
downloaded SVG work offline. No accounts or analytics.

It is meant for small animated workflows. Mermaid is useful when you want to
maintain a diagram as text, and a GIF is useful for recorded motion. Connections
here animate in order rather than simulating concurrent tasks.

Source: https://github.com/infinuts/readme-flow-svg

I'd like feedback on keyboard editing, README rendering, and workflows that are
hard to express with the current controls.
